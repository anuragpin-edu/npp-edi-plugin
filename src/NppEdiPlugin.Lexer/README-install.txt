NppEdiLexer Native PoC Installation

1. Create a directory named "NppEdiLexer" inside your Notepad++ plugins directory:
   C:\Program Files\Notepad++\plugins\NppEdiLexer\
   
2. Copy NppEdiLexer.dll into that new directory.

3. Copy NppEdiLexer.xml into the Notepad++ Config folder.
   For standard installation:
   %APPDATA%\Notepad++\NppEdiLexer.xml
   (If it doesn't work, try placing it in C:\Program Files\Notepad++\plugins\Config\)

4. Start Notepad++.
5. Verify "NppEdiLexer" appears in the Plugins menu.
6. Verify EDI X12, EDI EDIFACT, and EDI VDA appear in the Language menu.
